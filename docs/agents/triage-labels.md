# Triage

| Rôle | Label |
| --- | --- |
| À qualifier | `needs-triage` |
| Information indispensable manquante | `needs-info` |
| Spécification exploitable par un agent | `ready-for-agent` |
| Action humaine indispensable | `ready-for-human` |
| Abandonné | `wontfix` |

L'exécution emploie également `in-progress` et `done`. Un ticket prêt peut avoir des dépendances non terminées.
