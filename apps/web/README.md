# Application web DigiPM

Interface TanStack Start, routes HTTP Better Auth/oRPC et rendu React. Exécuter les commandes depuis la racine du monorepo pour charger les variables d’environnement et les packages partagés.

Voir le [README du projet](../../README.md) pour démarrer, le [guide d’exploitation](../../docs/operations.md) pour Docker et le [rapport de validation](../../docs/validation/delivery.md) pour l’état réel de l’implémentation.
