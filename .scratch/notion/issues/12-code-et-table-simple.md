# 12 : Écrire du code et une table simple dans une page

**What to build:** Un éditeur ajoute un extrait de code ou une petite table sans créer une base de données.

**Blocked by:** 05

**Status:** ready-for-agent

## Critères d'acceptation

- [ ] Bloc code avec langue et rendu déterministe ; table simple avec ajout/suppression de lignes/colonnes.
- [ ] Persistance, validation serveur et export interne de ces nœuds pris en charge.
- [ ] Navigation clavier, sélection multi-cellule supportée explicitement, copier/coller et undo testés.
- [ ] Limites pour tableaux excessifs et texte volumineux ; aucune confusion avec une source de données.
