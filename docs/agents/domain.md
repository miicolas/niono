# Documentation métier

Lire `CONTEXT.md` pour les termes du produit et les ADR de `docs/adr/` pour les décisions touchées. Le contexte métier reste unique même si l'implémentation emploie plusieurs packages.

Le glossaire contient les définitions métier ; le plan contient la conception ; les tickets contiennent les critères de réalisation. Une évolution d'architecture significative met à jour l'ADR concerné et les références correspondantes.
